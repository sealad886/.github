## Issues and pull requests

Create and resolve issues to coordinate work across chats and teams. A pull request can stand on its own. Link related issues in the [pull request template](.github/pull_request_template.md) and resolve them when applicable.

When creating a GitHub issue, set all applicable available fields and follow the reporting guidance in [CONTRIBUTING.md](CONTRIBUTING.md). When planning from an issue, review its fields, description, and comments.
